# Hand model

`right.glb` is the generic hand from [`@webxr-input-profiles/assets`](https://github.com/immersive-web/webxr-input-profiles) 1.0.19 (MIT, see LICENSE.md). It is skinned with WebXR joint names; `src/desktop/remote-hands.ts` poses it as the translucent hand shown when a teammate holds a part.
